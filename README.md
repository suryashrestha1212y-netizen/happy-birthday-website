# A Little Birthday Surprise

A responsive birthday website made with HTML, CSS, and JavaScript.

## Open in VS Code
1. Extract the ZIP file.
2. Open VS Code.
3. Choose **File → Open Folder** and select `happy-birthday-website`.
4. If VS Code asks whether you trust the folder, choose **Trust** only if this is the project ZIP you downloaded.
5. Open `index.html`.
6. Right-click inside the editor and choose **Open with Live Server** (install the Live Server extension if needed).

You can also open `index.html` directly in a browser.

## Files
- `index.html` — website content
- `style.css` — layout, colors, animations, responsive design
- `script.js` — menu, cake buttons, confetti, and surprise message

No Node.js or npm setup is needed. Internet is only needed for the optional Google Fonts; the website itself works without them.
